WHAT SEARCH ENGINES READ

This is STRUCTURED DATA, also called schema markup. Visitors never see it. Search engines and AI assistants read it to understand who a page is about and what they do. It is how a business gets its star ratings, hours, and prices to show up right in the search results.

"@type": "Person" tells them this page is about a person. "jobTitle" tells them what I do. "knowsAbout" tells them which topics to connect me with.

The code shown here is the actual schema running on this page. I set this up for every site I work on.

application/ld+json
{
  "@context": "https://schema.org",
  "@type": "Person",
  "name": "Gilmer Perez",
  "jobTitle": "Digital Growth Specialist",
  "knowsAbout": ["SEO", "Google Ads", "Meta Ads", "GA4",
                 "Next.js", "Technical SEO", "Web Development"]
}
